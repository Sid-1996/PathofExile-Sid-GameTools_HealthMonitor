# 安全自建 — 用源碼與套件自行運行

> 適用自 **v1.3.2** 起。
> 本頁教你三條互相獨立的使用路徑，選一條做就可以。
> 背景：近期 AI 攻擊與仿冒下載站頻傳，先把「只能下載 Setup.exe」改為「你也能自己從源碼驗證」。

## ⚠️ 先認唯一可信入口

| 渠道 | 唯一可信位址 |
|---|---|
| 官方套件下載 | https://github.com/Sid-1996/PathofExile-Sid-GameTools_HealthMonitor/releases |
| 源碼 | https://github.com/Sid-1996/PathofExile-Sid-GameTools_HealthMonitor |
| 問題回報 | https://github.com/Sid-1996/PathofExile-Sid-GameTools_HealthMonitor/issues |

- **只認 github.com 連結**：不要從第三方站、搜尋廣告、或 Chat 附件下載。
- 第三方標榜「最新版 Setup.exe」的一律是仿冒嫌疑。
- 若你在網路看到另一種域名（如 `.xyz` 鏡像站），直接不要點。

---

## 三條路徑總覽

| 路徑 | 適合誰 | 你實際在做什麼 | 信任根 |
|---|---|---|---|
| A — 源碼直跑 | 會裝 Python，想看 source | 下載 repo → `uv sync --locked` → `Run.bat` | GitHub repo source |
| B — 自建 EXE | 不想信任任何下載 exe | 在本機用 PyInstaller 打包 | 本機產出的 exe |
| C — 官方套件 | 只想最快用起來 | 下載 Releases 的 Setup.exe | GitHub Releases |

> 「套件」這詞在舊文件裡曾混指 B（自建）與 C（官方下載）。
> 本頁起統一定義：**自建 = B**，**官方套件 = C**，不要混稱。

---

## 路徑 A — 源碼直跑

最透明：你看到的就是將執行的程式。

### 需求

- Windows 10 / 11（64 位元）
- Python 3.13（https://www.python.org/downloads/，勾 Add to PATH）
- uv（https://docs.astral.sh/uv/getting-started/installation/）

### 步驟

```powershell
git clone https://github.com/Sid-1996/PathofExile-Sid-GameTools_HealthMonitor.git
cd PathofExile-Sid-GameTools_HealthMonitor
uv sync --locked
Run.bat
```

> `.venv` 會由 uv 自動建立並安裝 `uv.lock` 鎖定的精確版本
> （依賴不再是「有版本就裝哪個」，而是可重現的同一組）。

### 跑起來後如何驗證自己不是假站

1. 打開 `src\_version.py`，確認 `__version__` 與 Release tag 一致。
2. 在 repo 目錄跑 `git log -1`，commit 雜湊應在 GitHub 上看得到。
3. 全部邏輯都在 `src/`，任何時刻可逐行審查。

### 何時選 A

- 你不想信任任何下載來的 exe。
- 你願意花 5 分鐘建立 venv+pylock 相關環境。

---

## 路徑 B — 自建 EXE

你本機自行打包，產物只在本機。

### 需求

- 同 A，加上 PyInstaller 本身（已在 dev 依賴中）
- .NET SDK 8+ 與 `vpk` 只有**發版**需要，使用者自建 EXE 不需要

### 步驟

```powershell
uv sync --locked
scripts\build_exe.bat
Run.bat
```

- 產出位置：`dist\GameTools_Package\`（含 exe 與旁置資源）
- `Run.bat` 會優先找同層 exe → `dist\` exe → `.venv` 源碼

### 如何驗證自建產物

- 產物在你本機產生，先天沒有「外部植入」風險。
- 別再把自己產的 exe 上傳給他人當「官方版」使用。

### 何時選 B

- 你想有 exe 便攜，但不想信任 C 的下載。
- 你有基本命令列操作能力。

---

## 路徑 C — 官方套件

最快，但要認對入口。

1. 只進 https://github.com/Sid-1996/PathofExile-Sid-GameTools_HealthMonitor/releases
2. 下載 `Sid.GameToolsHealthMonitor-win-Setup.exe`（推薦）
3. **v1.2.1（含更早）請務必手動重裝**：自動更新會在下載階段失敗，請用 Setup.exe 覆蓋安裝（設定會保留）
4. 安裝後從開始選單啟動，之後程式會自動檢查更新（Velopack）

### 安裝後如何確認沒被冒充

- 在「設定 → 應用程式」看發行者/名稱為 `Sid.GameToolsHealthMonitor`
- 安裝路徑應為 Velopack 預設（`%LOCALAPPDATA%\Sid.GameToolsHealthMonitor` 附近）
- 存疑時：卸載，改用路徑 A / B 自建

---

## 三條路怎麼選？

| 你的情況 | 建議 |
|---|---|
| 只想快點玩，信任 GitHub | C |
| 不信任何 exe，要透明 | A |
| 要 exe，但不想下載 | B |
| 懷疑已中釣魚站 | 直接卸載，走 A 重裝 |

---

## 移除與重設

- 設定檔：`%LOCALAPPDATA%\GameTools_HealthMonitor\health_monitor_config.json`
  （`* .backup` 自動備份；刪掉它等於重設為預設）
- 截圖：同目錄 `screenshots\`
- 工具內 `工具設置 > 資料與重設` 可開啟資料夾 / 複製路徑 / 重設為預設
