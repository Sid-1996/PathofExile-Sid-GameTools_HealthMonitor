# Path of Exile Sid 輔助工具箱 - 運作原理

## 🎯 工具如何運作？

Path of Exile Sid 輔助工具箱是一個智慧型的遊戲輔助工具，它使用電腦視覺技術和自動化操作來幫助玩家更輕鬆地遊玩《Path of Exile》。以下是各項功能的基本運作原理：

## 🩸 智能血魔監控

**運作方式：**

1. 玩家在遊戲中框選血量條和魔力條的位置
2. 工具會持續監控這些區域的顏色變化
3. 當血量或魔力低於設定百分比時，自動按下補血/補魔按鍵

**為什麼有效：**

- 只監控玩家指定的小區域，不會影響遊戲效能
- 使用顏色分析來判斷血魔狀態，比數值讀取更安全
- 有多重安全檢查，避免誤觸發

**截圖機制：**

- 工具使用 Windows.Graphics.Capture（WGC）進行背景截圖，遊戲視窗被其他視窗遮擋或失去焦點時，監控仍能正確分析畫面
- 無法使用 WGC 時（如舊版 Windows 或獨佔全螢幕模式），自動降級為 mss 螢幕擷取（僅在遊戲為前景時結果正確）
- 遊戲視窗最小化時無法截圖（Windows 限制），監控會自動暫停並顯示提示，還原視窗後自動恢復
- 建議使用「視窗全螢幕」模式，可同时享受全螢幕畫面與背景截圖/浮層提示功能

## ⚡ 技能連段系統

**運作方式：**

1. 玩家設定一個觸發按鍵（例如 Q 鍵）
2. 設定要連續使用的技能順序和間隔時間
3. 按下觸發鍵後，工具會自動按順序執行所有技能

**為什麼有效：**

- 確保技能按鍵精確送達遊戲視窗
- 維持固定的技能間隔時間
- 可以隨時中斷連段執行

## 🎒 一鍵清包功能

**運作方式：**

1. 玩家開啟空背包，讓工具記住「空背包」的樣子
2. 工具記錄每個格子的位置
3. 使用時自動檢查每個格子是否有物品，有就點擊丟棄

**為什麼有效：**

- 只檢查背包區域，不會誤操作其他地方
- 有多重安全檢查，防止意外丟棄重要物品
- 可以緊急停止清包動作

## 🖱️ 自動連點工具

**運作方式：**

1. 按住 Ctrl + 左鍵啟動連點功能
2. 工具會持續點擊滑鼠當前位置
3. 鬆開按鍵即停止

**為什麼有效：**

- 精準控制點擊位置和頻率
- 只有在需要時才啟動，避免誤操作
- 穩定可靠的點擊節奏

## 🎯 其他實用功能

- **F5 快速回程**：一鍵回到藏身處
- **F6 一鍵取物**：記住多個位置，自動前往撿取物品
- **F9 全域暫停**：緊急停止所有自動功能
- **F10 血魔監控開關**：快速啟動/停止血魔監控
- **F12 安全關閉**：完全關閉工具

## 🔧 系統設計理念

### 安全第一

- 監控分析可在背景持續運行（WGC 背景截圖），但所有操控動作（按鍵、點擊）只在遊戲視窗為前景時執行，背景時僅分析不按鍵
- 多重驗證機制，避免誤操作
- 可以隨時暫停或停止任何功能

### 效能優化

- 只監控必要的畫面區域
- 根據電腦效能自動調整監控頻率
- 各功能獨立運行，不會互相影響

### 使用者友好

- 簡單的設定介面
- 詳細的操作說明
- 即時的狀態顯示

### 🔮 使用者行為預測

遊戲工具的使用者多數在**前景玩遊戲**、工具 GUI 多半**掛在背景**運作——因此凡需要使用者注意的警示訊息，**不應只放在 GUI 內**（狀態列或狀態 log），否則使用者根本看不到。

- **訊息要落在使用者看得到的地方**：需要使用者注意的訊息，以**不搶焦的置頂浮層（toast）**出現在螢幕角落，幾秒自動消失，不干擾遊戲操作，同時寫入狀態 log 留記錄。
- **防呆範例**：功能尚未設定就被觸發時，工具不默默無反應。例如按下 F6 一鍵取物但尚未設定取物座標，浮層會提示「尚未設定取物座標，請先設定座標」，使用者便知道為何沒作用。
- **限制**：獨佔全螢幕模式（exclusive fullscreen）下任何浮層都無法顯示（Windows 全螢幕無視窗層疊），需切到視窗／無邊框視窗模式才能看到浮層提示。
- **審視準則**：設計或修改功能時，以「使用者若看不到提示是否會困惑？」自我檢視，並確保訊息落在使用者當下會看的位置。

## 🔄 自動更新

- **安裝即更新**：`Setup.exe`（Velopack）安裝後，啟動時經 `GithubSource` 檢查 Releases 的 `nupkg`，僅下載差異（delta）後自動重啟套用
- **測試不擾民**：發版前可用測試倉 `Sid-1996/..._release-test` 實測（寫 `%LOCALAPPDATA%\GameTools_HealthMonitor\update_repo_override.txt` 切換），不影響正式用戶
- **設定不丟失**：更新只替換程式目錄，使用者設定與 `update_repo_override.txt` 位於 `%LOCALAPPDATA%\GameTools_HealthMonitor\`，可活過更新

## 🛡️ 安全保護

工具設計有多層安全保護：

1. **視窗檢查**：操控動作只在遊戲視窗活躍（前景）時執行
2. **冷卻機制**：避免連續重複觸發
3. **緊急停止**：多種方式可以立即停止所有功能
4. **設定保存**：自動保存設定到 `%LOCALAPPDATA%\GameTools_HealthMonitor\`，跨版本不丟失（含自動備份）

## 🎮 適用場景

- **新手保護**：自動補血補魔，減少死亡
- **高效 farming**：自動技能連段，提高輸出效率
- **背包管理**：快速清理背包，節省整理時間
- **重複任務**：自動連點，解放雙手

---

**總結：** 這個工具就像一個聰明的助手，它會觀察遊戲畫面，在適當的時機幫你執行重複的操作，讓你能夠更專注地享受遊戲樂趣。所有功能都經過精心設計，既安全又有效率。
